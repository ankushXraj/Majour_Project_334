# 🌸 FlowerCycle – Temple Flower Waste to Eco-Products Management System

**Turning Temple Flower Waste into Sustainable Products**

FlowerCycle is a web-based platform designed to manage temple flower waste collection and promote its conversion into useful eco-friendly products such as incense sticks, organic compost, natural colours, and decorative items.

The project aims to reduce environmental pollution caused by improper disposal of temple flowers and encourage sustainable waste management through resource recovery and recycling.

## 🎯 Objectives

- Reduce pollution caused by improper disposal of temple flower waste.
- Provide a digital platform for temple waste collection management.
- Connect temples, collection teams, and administrators.
- Track collected flower waste and its processing.
- Manage eco-friendly products generated from recycled flowers.
- Display collection statistics and reports.

## ✨ Key Features

### 1. Temple Portal
- Temple registration and login.
- Temple dashboard.
- Submit flower waste collection requests.
- View submitted requests and their status.

### 2. Collection Team Portal
- View available collection requests.
- Manage collection request status.
- Update requests from Pending to Collected and Processing.

### 3. Admin Dashboard
- Manage collection requests.
- View temple collection details.
- Create waste records from collected requests.
- Monitor overall project activities.

### 4. Waste Management
- Record collected flower waste.
- Track usable flower material.
- Track other collected materials.
- Maintain waste processing status.

### 5. Eco-Product Inventory
- Add and manage eco-friendly products.
- Track product quantities and prices.
- Monitor available stock.
- Calculate inventory value.

### 6. Reports & Analytics
- Total collection requests.
- Total flower waste received.
- Usable flower material.
- Other material collected.
- Total eco-product units.
- Collection status breakdown.

## 🚀 How to Run the Project

1. Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Open the project folder in VS Code.

3. Install the **Live Server** extension in VS Code.

4. Open `index.html`.

5. Right-click and select **Open with Live Server**.

6. The project will open in your browser.

## ⚙️ Current Project Status
